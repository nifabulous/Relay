# Changelog

All notable changes to Relay are documented here.

## [0.1.0.0] - 2026-08-25

### Added

- Redesigned the Learn, Explore, and Operate workspaces around Relay's token-based design system.
- Added bank-name search and a browsable bank directory with filters.
- Added Case Desk investigation workflows with evidence gathering and recovery states.
- Added payment tracking, STP validation, value-date, sanctions-screening, fee, and glossary surfaces.
- Added mobile-safe spacing for fixed navigation and Tutor controls.

### Changed

- Improved module completion persistence so finished lessons survive immediate navigation.
- Improved accessibility across settlement tables, menus, focus states, touch targets, and reduced-motion journeys.

### Fixed

- Fixed keyboard access for horizontally scrolling settlement instructions.
- Fixed stale test selectors and ambiguous status queries in browser coverage.
